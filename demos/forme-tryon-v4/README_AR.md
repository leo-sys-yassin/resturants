# FORME — استوديو التلبيس وإدارة المتجر V4

## ما يعمل الآن
- واجهة متجر بسلة وأسعار ومقاسات وكميات للقطع أو الطقم كاملًا.
- رفع صور منتجات مستقلة (وليست قصاصات من الموديل)، وإضافة القطع وتعديلها وحذفها.
- رفع موديلات، واختيار من قطعة إلى خمس قطع ووقفة أمامية أو مرتاحة.
- حفظ الصور والكتالوج على القرص بالخادم، أو IndexedDB في وضع معاينة HTML المحلي.
- تنفيذ طلبات تلبيس متعددة المراجع عبر OpenAI Images Edits، ثم عرض النتيجة للمراجعة، واعتمادها صراحة قبل ظهورها في المتجر.
- الإطلالات المعتمدة تحتفظ بنسخة أسعار وصور قطعها وقت التوليد؛ تعديل الكتالوج لا يغيّر قطع إطلالة قديمة بصمت.
- عينة تلبيس مولدة فعليًا مرفقة مع وقفة طبيعية وصور منتجات مستقلة مولدة للعرض. الأصول هنا أمثلة وليست منتجات براند المستخدم.

## الحالة الفعلية
تم توليد العينة المرفقة بأداة الصور المتاحة في المحادثة من مرجع هوية وصورة مرجعية للملابس. هذه العينة ليست ناتجة عن نداء API من الخادم المرفق. صور المنتجات المستقلة للعينة أيضًا صور AI توضيحية وليست صور مخزون حقيقي؛ ارفع صور منتجاتك الأصلية للاستخدام الفعلي.

لا يوجد OPENAI_API_KEY مهيأ في بيئة المهمة. لذلك **التوليد الجديد داخل الموقع غير مفعّل حتى إضافة المفتاح على الخادم**. لا يحاكي الزر نجاح التلبيس، ولا يحوّل تبديل الصور إلى نتيجة مزيفة. اختبارات المزوّد تستخدم محاكاة للاستجابة ولا تثبت اتصال حساب OpenAI فعليًا.

## تشغيل الخادم
1. ثبّت Node.js 22.9 أو أحدث. لا توجد اعتماديات npm للتشغيل.
2. انسخ .env.example إلى .env.
3. أضف OPENAI_API_KEY في .env على جهاز/خادم التشغيل، لا في HTML ولا في GitHub.
4. شغّل npm start، ثم افتح http://127.0.0.1:8902.

OPENAI_IMAGE_MODEL الافتراضي gpt-image-1.5؛ غيّره فقط إلى نموذج يقبل Images Edits متعددة المراجع. التوليد يستخدم صور القطع كلها مع هوية الموديل، ويطلب PNG بخلفية شفافة. نتيجة AI تقريبية وقد تغيّر تفاصيل دقيقة أو ملامح؛ راجعها قبل الاعتماد. هي معاينة ستايل، ليست قياسًا لمدى ملاءمة المقاس.

الصور والبيانات تحفظ في runtime/ (غير مضمّن بالمستودع). احتفظ بهذا المجلد للاستمرارية عند إعادة التشغيل/النشر. مهام المراجعة تحفظ في jobs.json؛ أي مهمة جارية عند توقف الخادم توسم كفشل دون إعادة توليد تلقائية.

للربط بشبكة عامة، يلزم ADMIN_TOKEN قوي وHOST مناسب وHTTPS. الخادم يرفض الربط العام دون رمز إدارة. رمز الإدارة يدخَل من تبويب الإدارة، ويبقى في ذاكرة الجلسة فقط. الملف ليس متجر إنتاج مكتملًا؛ لا يتضمن دفعًا أو مخزونًا أو إدارة مستخدمين.

## معاينة بدون تشغيل
افتح FORME_TryOn_Preview.html: الصور والخط والكود مدمجون. يتيح العرض ورفع/تعديل الكتالوج محليًا. **HTML وحده لا ينفّذ توليدًا جديدًا**؛ استخدم نسخة الخادم لهذا الغرض. النسخة الاحتياطية JSON تتضمن صور الكتالوج والإطلالات مدمجة.

## الاختبار
npm test: خمسة اختبارات تشمل الصور متعددة المراجع، ترويسة المفتاح على الخادم، الخطأ عند غياب المفتاح، عدم تكرار الطلب عند خطأ المزوّد، المصادقة، رفض ملفات SVG وحفظ الكتالوج عبر إعادة التشغيل.

check.py: فحص Playwright على الكمبيوتر والموبايل، رفع ملف وحفظه وإعادة تحميله، السلة والمجموع، نصوص الملفات غير الموثوقة، حالة غياب المفتاح، تحميل الصور، وعدم تجاوز عرض الشاشة. تشغيله يتطلب Playwright وChromium وخادمًا على المنفذ 8902.

تم فحص المعاينة المستقلة دون إنترنت. لا يوجد اختبار API توليد مدفوع مباشر لعدم وجود المفتاح.
