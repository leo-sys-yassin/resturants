# ANQA v10 — Warm materials and a larger, coordinated layout

فك الضغط وافتح ANQA_Showroom_v10.html. ZIP يحتوي HTML واحدًا بكل الخامات والخطوط والمجسمات داخله. المتجر ديمو، والسلة محلية.

- مساحة الداخل زادت من نحو 6×7.9م إلى 6.8×9.5م (نحو 36%). فصلت رفوف الإكسسوارات الخلفية عن ستاند الملابس بممر زاوية يتجاوز 60 سم، مع إعادة توزيع رفوف الأحذية والخزائن والكنزات والمقعد.
- جدران لياسة بيج كراميل دافئ #CFB295، وترافرتين الواجهة السابق بلون أدفأ. عروق الجوز أوضح مع زيادة خفيفة للتباين وnormal، مع إبقاء السطح ساتانًا دون لمعان زائد.
- الطاولة الوسطية 1.8×1.28م، مع قنوات حديدية مثبتة تحت حافتها وأربع شرائط LED متصلة بصريًا وإضاءة غير مباشرة دافئة محسوبة على الجسم والأرض، دون bloom. يضيف shader الخشب سقوط ضوء LED محليًا محسوبًا بالمسافة واتجاه السطح، محصورًا بجسم الطاولة، ليبقى الضوء واضحًا مع عروق الخشب.
- نفس تصميم السقف وعدد الخطوط وارتفاعها وألوانها وقدرتها؛ مُدّدت الأطوال مع توسيع الغرفة فقط، وتحركت الإنارة الطرفية مع الجدار. لا سبوتات إضافية. ceiling-verification.json يسجل المقارنة مع v9.
- أبواب تفتح للخارج وخلوص 5 مم فوق العتبة، مع الحفاظ على الزجاج والواجهة والهوية.
- إطالة مسافة السكرول لتناسب المتجر الأكبر، وإعادة ضبط مسار الجولة ونقاط المشي وأحجام منع النقر عبر الأثاث. مسارات المشي تمر حول الطاولة الأكبر، وعرض القطعة ودورانها والسلة واللمس باقية.

## البناء والتحقق
```sh
blender -b -t 6 --python authoring/build_architecture.py
blender -b -t 2 --python authoring/optimize_export.py
python authoring/denoise_lighting.py
blender -b -t 2 --python authoring/verify_ceiling.py
blender -b -t 2 --python authoring/verify_structure.py
python authoring/smooth_irradiance.py
npm run build
python -m http.server 8930
python test.py
```

الإضاءة الثابتة محسوبة في Cycles، وخريطة الإضاءة 3072px مستقلة عن خامات PBR المصوّرة 2K. تنقية التشويش محصورة بخريطة الإضاءة؛ لا يوجد تمويه شاشة أو عمق مجال؛ أزيل تدرج الهيدر الذي كان يغطي أعلى المشهد بضباب فاتح. الرسم يدعم كثافة 2× مع فلترة خامات مائلة حتى 16×، مع بقاء خامات الأقمشة والخشب والحجر مستقلة وحادة. الكنزات تضاء بمصادر LED حية. عمارة الشارع خلفية مولّدة، والطريق والرصيف مجسمات. verification.json يسجل نتيجة فحص المتصفح وبصمة HTML. الفحص بمتصفح برمجي لا يقيس FPS على هاتف فعلي. مصادر الخامات وتراخيصها في assets/MATERIAL-SOURCES.md.
