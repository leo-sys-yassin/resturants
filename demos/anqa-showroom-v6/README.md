# ANQA v6 — connected 3D facade and reference wall

افتح **ANQA_Showroom_v6.html** بعد فكّ الضغط. الملف مستقل ويتضمن الصور والخطوط والمجسّمات. نسخة واجهة ديمو، لا ترسل طلبات شراء.

## التغيير
- أزيلت طبقة الصورة الثابتة وطبقة الأبواب CSS من الإصدار الخامس تمامًا.
- الواجهة الآن جسم حجري بعمق 40 سم وفتحة دخول حقيقية. خامة الصورة الأصلية مُسقطة على الحجر واللوغو فقط، وليس على الزجاج أو خلفية الداخل.
- البابان والزجاج الجانبي والعلوي عناصر في نفس مشهد WebGL. يدور البابان حول المفصلات الخارجية، والكاميرا تمر بينهما إلى المتجر دون استبدال مشهد أو تلاشي.
- استُبدل جدار الملابس القديم بالكامل بجدار الترافرتين في المرجع PDF: وحدة ضيقة مفتوحة ووحدتان عريضتان، هياكل معدنية سوداء، قضبان، رفوف وخزانات حجرية سفلية وإضاءة مخفية.
- الملابس الحالية معلّقة على القضبان الجديدة، مع الاحتفاظ بتفاصيل القطع والسلة المحلية ودوران المجسّم نفسه.

## حدود المطابقة
الصورة مرجع للخامات والتكوين؛ الجزء الداخلي الذي يظهر وراء الزجاج هو المتجر التفاعلي الحقيقي، لذلك لن يكون صورة فوتوغرافية مطابقة لبكسلات المرجع. الحجر الخارجي يحمل الإضاءة والظلال الأصلية المرسومة في المرجع، بينما الزجاج والأبواب تتغير انعكاساتها بحسب زاوية الرؤية. لا يوجد عرض إنسان في هذه النسخة.

## البناء
```sh
npm install
blender -b -t 6 --python authoring/build_architecture.py
blender -b -t 2 --python authoring/refine_frames.py
blender -b -t 2 --python authoring/reexport.py
npx esbuild app.js --bundle --minify --outfile=app.bundle.js
python build.py
python -m http.server 8926
python test.py
```

المواد والصور المرجعية مقدمة من المستخدم. تشمل الأصول البيئية مواد Poly Haven (CC0)، وThree.js (MIT)، وخطوط OFL كما في ملفات التراخيص ضمن assets. ملف verification.json يسجل الاختبارات؛ الصور ضمن review محلية وليست جزءًا من الأصول اللازمة للتشغيل.
