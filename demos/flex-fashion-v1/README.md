# FLEX FASHION — Desktop concept v1

واجهة متجر مستقلة للكمبيوتر، مستوحاة من حركة الستاند في الفيديوهين المرفقين. تصميم جديد باسم FLEX FASHION بخلفية محايدة وهوية برتقالية خفيفة.

## فتح النسخة

نزّل `Flex_Fashion_Standalone.html` وافتحه مباشرة في Chrome أو Edge على الكمبيوتر. الصور والخط موجودان داخل الملف، ولا يحتاج إلى تحميل مكتبات أو الاتصال بالإنترنت.

أو فك ZIP وافتح `index.html`. لتشغيل خادم محلي اختياري: `python -m http.server 8910`، ثم افتح `http://localhost:8910`.

## التفاعلات

- هيرو يتحول بالسكرول إلى ستاند معدني منحني.
- خمس قطع تتحرك بالأسهم أو السحب، وتتحول بين الواجهة والمنظر الجانبي.
- اضغط القطعة المحددة لفتح التفاصيل والألوان والمقاسات والكمية.
- THE PIECE / ON MODEL لعرض القطعة منفردة أو على الموديل.
- FRONT / RIGHT / BACK / LEFT، أو السحب، للتنقل بين أربع صور مختلفة لكل وضع.
- بحث وسلة محفوظة محلياً ودليل مقاسات وملخص المشتريات.
- دعم لوحة المفاتيح وتقليل الحركة حسب إعداد الجهاز.

## حدود النسخة والصور

هذه واجهة ديمو للكمبيوتر؛ نسخة الهاتف مرحلة لاحقة. الصور فوتوغرافية المظهر **مولّدة بالذكاء الاصطناعي** للمشروع، وليست صور مخزون تجاري مصوّر أو صوراً مأخوذة من الفيديو. لكل قطعة ثماني صور مستقلة: أربع جهات للقطعة وأربع جهات لنفس الموديل بها. الانتقال بين الجهات يستخدم صوراً متعددة وتحريكاً بصرياً، وليس نموذج قماش ثلاثي الأبعاد أو تجربة قياس تلقائية للملابس التي يرفعها المستخدم.

الأسعار والمقاسات والخامات أمثلة للعرض. لا توجد مدفوعات أو طلبات حقيقية أو حساب مستخدم أو لوحة إدارة. معلومات الشحن والتواصل تُضاف عند ربط المتجر الفعلي. تصميم الحركة مبني على المرجع البصري، وليس ادعاء تطابق حرفي مع كود الموقع الأصلي.

## تعديل المنتجات

عدّل `catalog.json` لاستبدال الأسماء والأسعار والألوان ومسارات الصور الثمانية لكل قطعة. استخدم صوراً متسقة الاتجاه والمقاس وبخلفية شفافة. استبدال الصور يحتاج توفير الجهات المطلوبة للقطعة والموديل؛ لا يتم توليدها تلقائياً داخل الصفحة.

شغّل `python build.py` لتحديث `catalog.js` وإنشاء HTML مستقل وZIP. الخط Montserrat مرفق بترخيص OFL في `assets/montserrat-OFL.txt`.

## التحقق

اختبارات متصفح Chromium تشمل الصور الأربعين، السكرول، حركة الستاند والسحب، تبديل الألوان والجهات، المقاسات والكمية، السلة وحفظها، البحث ودليل المقاسات، وشاشات 1280×800 و1440×900 و1920×1080 وتقليل الحركة. راجع `verification.json`.

لتشغيل التحقق الآلي: ثبّت Python Playwright وشغّل خادماً على المنفذ 8910، ثم `python test_shop.py`. يحتاج Chromium في `/usr/bin/chromium` ويمكن تعديل مساره في الاختبار.
