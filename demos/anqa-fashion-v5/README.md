# ANQA — Atelier 05

افتح ANQA_v5.html مباشرة، بما فيه من صور وخطوط وأصول مضمنة. يحتاج العرض الثلاثي للقطعة متصفحاً يدعم WebGL، ولا يحتاج الملف شبكة بعد تنزيله.

## هذه النسخة
- استعادة صور الشخص الأصلية المولدة بالذكاء الاصطناعي من ANQA v2، لجميع القطع الخمس.
- زوايا منفصلة بأزرار أمامي/يمين/خلفي/يسار. لا دمج بين الصور ولا تشويه للمجسم البشري.
- العرض الفوتوغرافي ليس دوران إنسان ثلاثي الأبعاد متواصلاً، ولا يحتوي حركة يدين. دوران القطعة الثلاثي الأبعاد يبقى مستقلاً.
- خطوط جديدة: Amiri للعناوين العربية، IBM Plex Sans Arabic لواجهة الاستخدام، Cormorant Garamond للعناوين الإنجليزية. تراخيص الخطوط في assets.
- قائمة جانبية مستقلة للعودة للرئيسية ودليل المقاسات، مع عرض المنتج بلا إطار.
- دعم العربية والإنجليزية، المقاسات والكمية والحقيبة التجريبية.

المجسمات التقريبية للملابس من الإصدار السابق لم يُعَد بناؤها؛ لا تُعد هذه النسخة مسحاً احترافياً للمنتج. لا يوجد دفع أو طلبات حقيقية.
