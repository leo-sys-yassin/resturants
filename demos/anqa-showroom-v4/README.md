# ANQA — Atelier / revision 04

افتح **ANQA_Showroom_v4.html** مباشرة بعد تنزيله. لا يحتاج سيرفرًا أو اتصالًا بعد التنزيل. نسخة المتجر تجريبية ولا ترسل طلبات أو تحصّل دفعات.

## التعديل
- إعادة بناء بنية المتجر مع حواف حجر مستديرة، بلاطات مفصولة بفواصل صغيرة، تجاويف رفوف خشبية، إضاءة أسفل الرفوف، وطاولة بقاعدة خشب مخدّد.
- حساب الضوء المباشر والمرتد في Blender Cycles ثم تخزينه في خامة 4096×4096. إزالة ضجيج الحساب باستخدام Open Image Denoise RTLightmap. تُعرض العمارة ككتلة واحدة بخامتها المحسوبة مسبقًا، لتقليل كلفة الإضاءة أثناء الجولة.
- إضافة تفاصيل عروق خشب مصوّرة فوق الإضاءة المحسوبة، وإضاءة مباشرة للملابس المتحركة، وظل خفيف على الجدار.
- زجاج فعلي بخاصية transmission وIOR 1.5، مع لوح علوي ثابت يتبع قوس الواجهة. انعكاسات من HDR خارجي.
- استبدال مجسّمات الملابس الخمسة: إعادة بناء SAM 3D Objects من صور المجموعة الأصلية، إزالة بقايا التعليقات والأجزاء المعزولة، تنعيم حدود الرقبة، وإعادة ضبط المقياس. تفاصيل الإصلاح في garment-repairs.json.
- القضبان الأربعة من هندسة TubeGeometry متصلة، مع زوايا منحنيّة مماسية، دون تقاطع أسطوانتين. القضيب العلوي طوله المستقيم 4 أمتار.
- تصغير الجزء الخشبي من التعليقة وإدخاله داخل الكنزة. يبقى الخطاف ثابت الاتجاه حول القضيب عندما تلتف القطعة.
- الحفاظ على الجولة، امتداد المحل إلى 7.6 متر، عرض القطعة الجانبي، اللمس للمعاينة، عارض 360 درجة، الحقيبة، وقسم عن أناقة.

## حدود الدقة
هذه محاكاة متجر تفاعلية وليست تصويرًا لمتجر قائم أو مسحًا ثلاثي الأبعاد له. الإضاءة المعمارية ثابتة ومحسوبة مسبقًا، والانعكاسات تعتمد على HDR؛ لا تُحاكي كل جسم خارج المحل لحظيًا. الأجزاء الخلفية للملابس مستنتجة بالذكاء الاصطناعي من الصور الأمامية، فلا تُستخدم لتوثيق تفاصيل مخزون حقيقي. لا ندّعي تطابقًا فوتوغرافيًا كاملًا مع صورة AURA. سلاسة الأجهزة الفعلية تعتمد على المتصفح ومعالج الرسوميات.

## الاستخدام
مرّر للدخول؛ السحب داخل المحل يغيّر اتجاه النظر. المرور بالماوس على القطعة يلفّها للأمام. على الهاتف، اللمسة الأولى للمعاينة والثانية للتفاصيل. اسحب أفقيًا في عارض القطعة لدورة كاملة، أو استخدم الأسهم. زر الأمام يعيد اتجاه القطعة.

## البناء والفحص
```
npm install
npm run build
python -m http.server 8924
python test.py
```
اختُبر HTML المستقل عبر localhost، ثم قُطع الاتصال أثناء التفاعلات. الفتح المباشر عبر file:// محظور في متصفح بيئة الفحص، لذلك لم يُختبر هذا المسار هنا. اختبار المتصفح يتناول تحميل العمارة والقطع، اتصال القضبان، المعاينة، دورة 360° مع ثبات الهندسة والخامة، الحقيبة، اللمس، عدم تجاوز عرض الهاتف، وإغلاق النوافذ والعودة للجولة. verification.json يتضمن النتائج وبصمة HTML الذي اختُبر.
