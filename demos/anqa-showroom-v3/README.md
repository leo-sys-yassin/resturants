# ANQA Showroom — extended space and garment interaction 03

افتح ANQA_Showroom_v3.html مباشرة. الملف مستقل ويحتاج متصفحًا يدعم WebGL.

## التغييرات
- زيادة عمق المحل من 5.6 إلى 7.6 متر باتجاه الواجهة، مع نقل المدخل والدرجات والزجاج وتعديل السقف ومسار الكاميرا وإضافة رفوف وستاند في الامتداد.
- تحريك طاولة العرض 65 سم باتجاه المدخل.
- عرض القطع جانبيًا على الستاند، والتفاف القطعة المختارة للأمام عند مرور الماوس. على الهاتف: اللمسة الأولى للمعاينة، والثانية للتفاصيل.
- عارض مجسم 360 درجة داخل تفاصيل القطعة، يدور أفقيًا بالسحب بدون تبديل الصور أو المجسم. أزرار دوران، ودعم أسهم لوحة المفاتيح وHome، مع خيار صورة القطعة.
- قسم «عن أناقة» بعد الجولة، مع العودة للمدخل وفتح المجموعة.
- الرسم عند الحاجة فقط، وإعادة استخدام عارض القطع، واحترام إعداد تقليل الحركة.
- مسار كامل: الواجهة، الدخول، رفوف الأحذية، داخل المحل، الملابس، الخروج، ثم إعادة عرض الواجهة وإغلاق الأبواب.
- دوران النظر بالماوس مقفول قبل الدخول وبعد الخروج، ومتاح فقط داخل المحل. اتجاهات الكاميرا تتغير باستخدام quaternion slerp لتجنب انقلابات اتجاه النظر.
- الحفاظ على تقسيمات المحل والستاندات والسقف والمقعد والطاولة.
- خامات سطحية مصوّرة للجدران والخشب والبلاط مع normal/roughness maps، وبيئة HDR محايدة للانعكاسات.
- زجاج بنفاذية وانكسار وسماكة بدل سطح شفاف بسيط، مع عدم جعله يحجب ضوء الشمس كجدار مصمت.
- كرت منتج أكبر من عمودين للكمبيوتر، ونافذة سفلية للهاتف، وتنقيح القوائم.

## حدود النتيجة
هذا تحسين لمشهد WebGL تفاعلي، وليس صورة فوتوغرافية أو نسخة مطابقة لصورة AURA. الانعكاسات تعتمد على بيئة HDR ثابتة، وليست انعكاسات آنية لجميع الأشياء خلف الزائر. مجسمات الملابس التقريبية القديمة باقية. الألوان والإضاءة والأداء تختلف بحسب الشاشة والجهاز. لا دفع ولا إرسال طلبات ولا مخزون حقيقي.

## التحقق
`test.py` يختبر ملف HTML المستقل مع قطع الشبكة بعد تحميله، بعرض 1440 و390 بكسل: دخول وخروج، التفاف القطعة، دورة كاملة 360° مع ثبات الهندسة والخامة، الكمية والحقيبة، المعاينة باللمس، وقسم عن المتجر. النتائج وبصمة HTML في verification.json. الاختبار يستخدم تقليل الحركة لضبط التوقيت؛ سلاسة الأجهزة الفعلية لم تُقَس.
