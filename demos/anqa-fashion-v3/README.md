# ANQA — أناقة · Desktop v3

واجهة ديمو للكمبيوتر، بالعربي والإنجليزي، مع دوران ثلاثي الأبعاد ثابت للقطع والموديل.

## افتح الموقع

افتح **ANQA_v3.html** الموجود مباشرة في جذر ZIP. الملف مستقل ويضم الخطوط والصور والمجسّمات والكود؛ لا يحتاج إنترنت أو تثبيت.

مجلد `ANQA_Source` يحتوي الملفات القابلة للتعديل. فك ضغطه كاملاً قبل فتح `index.html` أو تشغيل `python -m http.server 8913`. لا تفتح index وحده من داخل ZIP، لأن Windows قد يستخرجه دون ملفات التنسيق المجاورة.

## ما تغيّر

- أُزيلت تسلسلات الصور المدمجة واللقطات الوسيطة. الدوران يغيّر زاوية مجسّم جامد واحد، دون تغيير رؤوسه أو مقياسه أو ملمسه أثناء السحب.
- أُنشئ الخطاف والتعليقة والحديد هندسياً في المشهد نفسه. الحركة الخفيفة تتم حول نقطة التعليق.
- هيرو بالسكرول ينتقل إلى الريل، ثم عرض تفاصيل مفتوح بلا إطار حول القطعة.
- خطوط Noto أوضح وأكبر، وألوان نص بتباين أعلى. زر اللغة يترجم التنقل والمنتجات والتفاصيل والبحث والسلة ودليل المقاسات، ويبدّل اتجاه النص.
- خُفّض حجم الملف المستقل بحوالي72% عن v2. تُجهز خامات الموديلات عند الحاجة؛ يتوقف الرسم عند السكون وعندما يغيب المشهد عن الشاشة أو تصبح الصفحة بالخلفية.
- عند اكتشاف رسم برمجي دون تسريع رسومي، تقل دقة طبقة المجسّم أثناء الحركة وتعود أعلى عند التوقف. النصوص والأزرار تحتفظ بدقتها الأصلية.

## التحكم

اسحب الريل أو استخدم الأسهم، ثم اضغط القطعة المحددة لفتح التفاصيل. اسحب القطعة بالماوس للدوران. زر الموديل يبدّل بين القطعة وحدها وعرضها على الموديل. نقرتان أو Home يعيدانها إلى الأمام؛ أسهم لوحة المفاتيح تدور15درجة. زر الرجوع يعيدك إلى الريل، ومنه يمكنك العودة إلى البداية.

المقاسات والكمية والألوان والبحث والسلة وملخص الاختيارات تعمل في الديمو. تُحفظ السلة واللغة في المتصفح.

## حدود الصور والمجسّمات

المجسّمات **تقريبية**، أُعيد بناؤها محلياً من الصور الأصلية ذات الجهات الأربع، مع ملمس واحد ثابت مخبوز على كل سطح. هي ليست مسحاً ضوئياً دقيقاً لإنسان أو قطعة ملابس حقيقية، وقد تظهر تبسيطات في الأنف أو اليدين أو طيات القماش عند الزوايا الجانبية. الصور الأصلية مولدة بالذكاء الاصطناعي. لا تُستخدم صور الفيديو المرفق كأصول للموقع.

لا توجد لقطة تتحول إلى لقطة أثناء الدوران، ولا محاكاة قماش أو حركة ذراع أو تجربة قياس تلقائية لصور يرفعها الزائر. وضعية المجسّم ثابتة. استبدال مجسّمات الديمو بملفات GLB مصورة أو مصممة بدقة أعلى يحسّن تطابقها مع مخزون متجر فعلي.

هذه واجهة كمبيوتر؛ لم تُنجز نسخة هاتف. الأسعار والخامات والقياسات أمثلة. لا توجد مدفوعات أو طلبات فعلية أو حساب مستخدم أو لوحة إدارة.

## تعديل وبناء

- `data.json`: أسماء وأسعار وألوان بالعربي والإنجليزي.
- `i18n.js`: نصوص الواجهة.
- `style.css`: الهوية والأحجام والخطوط.
- `engine.js`: مشهد Three.js والريل والمجسّمات.
- `app.js`: التفاعلات والسلة واللغة وجدولة الرسم.
- `assets/*.glb`: المجسّمات مع الملمس المدمج. نظام إحداثياتها موحد حول أصل المشهد، ولا يُفترض أن أي GLB عشوائي يناسب نقطة التعليق دون ضبطه.

لتعديل الكود: `npm ci` ثم `npm run build`. للبناء من الحزمة المجمعة الموجودة، يكفي `python build.py`. ينتج `data.js` الذي يضم المجسّمات، وHTML المستقل، وZIP كاملاً. الخادم لا يحتاج API أو خدمة توليد أو حساباً خارجياً.

Three.js بترخيص MIT مرفق في `THREE-LICENSE.txt`. تراخيص خطوط Noto مرفقة في `assets/FONT-LICENSE.txt`.

## التحقق

راجع `verification.json`. تشمل الاختبارات ثبات بيانات المجسّم والمقياس والملمس أثناء الدوران، جميع القطع والجهات، اتصال الخطاف بالريل، توقف الرسم عند السكون، اللغتين والبحث والسلة والمقاسات، وأحجام1280×800 و1440×900 و1920×1080. يختبر `test_app.py` الواجهة عبر Chromium/Playwright عند تشغيل خادم على8913.

قياسات الأداء داخل هذا التنفيذ تستخدم SwiftShader البرمجي، ولا تمثل اختباراً على كرت شاشة فعلي. الملف المستقل اختُبر بعد تحميل HTML وحده مع إيقاف الشبكة تماماً؛ منع المتصفح المُدار تنقل file:// المباشر.

اختبار `test_360.py` يفحص دورتين كاملتين بالسحب للقطعة والموديل، ويتحقق من ثبات بيانات المجسّم ومقياسه وملمسه، ومن أن السحب العمودي لا يسبب ميلاً أو دوراناً. الإمساك بالماوس يوقف الزخم السابق فوراً.
