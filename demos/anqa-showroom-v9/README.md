# ANQA v9 — Walnut, warm plaster and outward doors

افتح ANQA_Showroom_v9.html بعد فك الضغط. الأرشيف يحتوي ملف HTML واحدًا بكل موارده المضمّنة. هذه واجهة ديمو مع سلة محلية.

## التصميم
- جدران بيج دافئ #D8C7B4 ولياسة ناعمة؛ خزائن وطاولة وألواح عناوين وخلف اللوغو بقشرة جوز طبيعية PBR موحدة.
- رفوف الأحذية والإطارات حديد أسود مطفي #1E1E1E مع خشونة طلاء دقيقة؛ مثبتات الرفوف والوصلات واضحة، والقواعد والأرجل تصل للأرض.
- أرضية حجرية جريج دافئ، تفاصيل دقيقة وانعكاس خفيف. حجر الواجهة السابق محفوظ.
- السقف وهندسته وأبعاده ومواضع وعدد خطوط إنارته **مطابقة تمامًا لـv8**. ceiling-verification.json يسجل مقارنة الهندسة والتحويلات ومصادر ضوء السقف.
- تحسين إضاءة الأثاث فقط: LED دافئة 3000K تحت الرفوف، إضاءة مخفية خفيفة تحت سطح الجزيرة، وهالة ناعمة خلف اللوغو دون bloom.
- البابان يفتحان للخارج حول مفصلاتهما الثابتة، مع خلوص 5 مم على الأقل فوق درجة المدخل. منظور أوسع قليلًا 66° للمكتب و68° للهاتف مع اتجاه الجولة السابق.

## الواقعية والأداء
صور خامات الجوز واللياسة ممسوحة فعليًا، بمقاس UV مرتبط بأبعاد العالم، وخرائط لون/خشونة/normal منفصلة. لا تمويه شاشة أو مؤثر bloom. الإضاءة غير المباشرة والظلال الثابتة محسوبة في Cycles ومنفصلة عن لون الخامات. الكنزات الحية تستقبل إضاءة LED مباشرة، وتبقى قابلة للدوران كالمجسم نفسه.

أصلح إعادة اختيار نقطة الجولة نفسها كي يبقى التحكم نشطًا؛ زر إعادة النظر يحتفظ بمجال الرؤية الأوسع. التنقل 360° ونقاط المشي حول الجزيرة، تكبير العجلة، اللمس، عرض المنتجات والسلة باقية. التصيير يتوقف عند السكون، والتفاعل يستعمل مجسمات نقر بسيطة. خلفية عمارة الشارع صورة مولّدة بعيدة؛ الطريق والرصيف مجسمات. فحص Chromium البرمجي لا يعادل قياس FPS على هاتف فعلي.

## البناء والفحص
```sh
blender -b -t 6 --python authoring/build_architecture.py
blender -b -t 2 --python authoring/optimize_export.py
python authoring/denoise_lighting.py
blender -b -t 2 --python authoring/verify_structure.py
blender -b -t 2 --python authoring/verify_ceiling.py
npm run build
python -m http.server 8929
python test.py
```

verification.json يحفظ نتائج اختبار HTML النهائي وبصمته. مراجعات الجدران الأربعة والصور ضمن preview-*.png خارج أرشيف التنزيل. مصادر وتراخيص الخامات في assets/MATERIAL-SOURCES.md.
