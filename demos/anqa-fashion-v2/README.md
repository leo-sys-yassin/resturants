# ANQA — أناقة | Desktop v2

واجهة ديمو مستقلة للكمبيوتر، مطوّرة من النسخة السابقة باسم وهوية **ANQA — أناقة**.

## الاستخدام

نزّل `ANQA_Standalone.html` وافتحه في متصفح كمبيوتر حديث. الملف موجود أيضاً مباشرة في جذر ZIP، بجانب `START_HERE.txt`؛ هذا هو ملف المعاينة الجاهز للفتح. الصور والخط ومحرك العرض موجودة داخله؛ لا يحتاج تحميل مكتبات من الإنترنت.

مجلد `ANQA` داخل ZIP يحتوي الملفات القابلة للتعديل. لفتح `ANQA/index.html` يجب فك ضغط مجلد `ANQA` كاملاً أولاً، مع إبقاء الصور والتنسيق وبقية الملفات بجانبه. فتح `index.html` وحده من داخل ZIP قد يعرض الصفحة دون تصميم لأن Windows يستخرجه منفرداً إلى مجلد مؤقت. تشغيل خادم محلي اختياري: `python -m http.server 8912`.

- السكرول ينقل الموديل والكتابة من الهيرو إلى الستاند المعدني.
- اسحب الريل أو استخدم الأسهم لاختيار قطعة. اضغط القطعة المحددة لفتح التفاصيل.
- اسحب القطعة بالماوس للدوران. تتحكم مسافة السحب بزاوية العرض مع إكمال حركة خفيف عند الإفلات.
- `SEE IT ON MODEL` يعرض الموديل بالقطعة، مع حركة دخول قصيرة يمسك فيها طرف الكنزة، وبنفس تحكم السحب.
- انقر مرتين على العرض للرجوع إلى الأمام. لوحة المفاتيح: أسهم يمين/يسار للدوران وHome للواجهة.
- `BACK TO RAIL` للرجوع إلى الستاند، و`BACK TO INTRO` للهيرو.
- الألوان والمقاسات والكمية والبحث والسلة ودليل المقاسات تعمل في الديمو. السلة تُحفظ في المتصفح.

## الجديد

هيرو مرتبط بالسكرول، ربط خطافات القطع بمسار الريل، إزالة صور الزوائد، تمايل خفيف ناتج عن تسارع السحب بدلاً من اهتزاز الماوس عند المرور، عرض مفتوح بلا بطاقات خلف صور القطع، وتحكم دوران مبسّط بلا أربعة أزرار للجهات.

## كيف يعمل الدوران وحدود النسخة

يعرض كل منتج تسلسلاً من **64 لقطة شفافة** للقطعة و64 لقطة للموديل؛ تُرسم لقطة واحدة في Canvas حسب زاوية السحب. مصادر القطع تتضمن 8 زوايا أصلية، ومصادر الموديل 16 زاوية، مع توليد اللقطات البينية باستخدام RIFE. صور الجهات الخلفية والجانبية مستقلة وليست انعكاساً للواجهة. لا يتم خلط صورتين فوق بعض أثناء السحب.

الصور فوتوغرافية المظهر مولّدة بالذكاء الاصطناعي، وليست جلسة تصوير بشرية حقيقية أو صوراً مقصوصة من الفيديو المرجعي. الدوران عبارة عن تسلسل صور كثيف، **وليس مجسماً بشرياً أو محاكاة قماش ثلاثية الأبعاد**؛ قد تظهر فروق طفيفة بين الزوايا. حركة اليد عند الدخول جزء من هذا التسلسل، وليست تحكماً حياً بالذراع أو القماش.

هذه نسخة كمبيوتر للمراجعة. لا توجد مدفوعات أو طلبات حقيقية أو لوحة إدارة أو تجربة قياس تلقائية لصور يرفعها الزائر. الأسعار والخامات وجدول المقاسات أمثلة، وتُستبدل بمعلومات المتجر عند ربطه.

## تعديل المشروع

عدّل `catalog.json` لتغيير البيانات ومسارات صور المعاينة وملفات تسلسل الدوران. كل Atlas يحتوي 64 إطاراً بقياس384×512 مرتبة في8 أعمدة×8 صفوف. `sequences.product.hookX` يحدد مكان الخطاف الأفقي لكل إطار لربطه بالريل. استبدال الملابس بصورة مفردة لا يولّد الجهات تلقائياً؛ يجب تجهيز تسلسل الدوران المقابل.

شغّل `python build.py` لتحديث `catalog.js` وإنتاج HTML مستقل وZIP. هذا البناء يستخدم مكتبات Python القياسية فقط؛ لا يحتاج نماذج توليد.

الخط Montserrat مرفق بترخيص OFL داخل `assets`. استُخدم [Practical RIFE](https://github.com/hzwer/Practical-RIFE) لإنتاج اللقطات الوسيطة أثناء إعداد الأصول؛ لا يعمل النموذج داخل الموقع ولا يحتاج الموقع خدمة خارجية. راجع `asset-provenance.json` للتفاصيل.

## التحقق

راجع `verification.json` لنتائج اختبار التفاعلات والمتصفح والأحجام. الاختبار الآلي `test_shop.py` يحتاج Python Playwright وChromium وخادماً محلياً على8912. ملفات الصور والخط مطلوبة بجانب `index.html`؛ الملف المستقل يضمها كلها.
