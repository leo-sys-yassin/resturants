# ANQA — original-photo entrance / v5

افتح **ANQA_Showroom_v5.html**. ملف مستقل يحتوي الصور والمجسمات والخطوط. لا حاجة إلى تشغيل index.html أو سيرفر للعرض المحلي.

## الواجهة المعتمدة
صورة assets/facade-original.png هي الصورة الأصلية المستخرجة من ZIP المستخدم، دون تعديل أو إعادة توليد. تُعرض كاملة بلا قصّ أو تمديد للنسب. الحجر، اللوغو، الإنارة، الزجاج الجانبي والعلوي كلها من الصورة الأصلية.

لتحريك البابين، أُنشئت طبقة خلفية بلا الأبواب الأمامية بواسطة أداة تحرير الصور. تظهر هذه الطبقة **داخل فتحة البابين فقط**؛ أي اختلاف خارج هذه الفتحة في الصورة المعدلة لا يُستخدم في الموقع. يُعرض البابان كعنصرين مستقلين بإطارات برونزية ومسكات وزجاج شبه شفاف، ويدور كل منهما إلى الداخل حول طرفه الخارجي حتى 82 درجة. لا تتحرك صورة الداخل مع الزجاج.

عند الإغلاق تظهر الصورة الأصلية وحدها. فتح البابين متاح بالتمرير أو زر «افتح البابين». «أغلق البابين» يعيد المشهد الأصلي. «دخول المتجر» يستكمل الجولة التفاعلية السابقة، والعودة للمدخل تعيد واجهة الصورة. واجهة المحل لا تدور بالماوس.

## حدود التعديل
- الخلفية المكشوفة بعد إزالة إطارات البابين ومسكاتها مستكملة بالذكاء الاصطناعي؛ لا يمكن استخراج البكسلات المحجوبة من صورة واحدة.
- الإطارات والمسكات المتحركة إعادة بناء مضبوطة على إحداثيات الصورة، وليست أجزاء فوتوغرافية مقصوصة مع خلفيتها.
- المشهد داخل الموقع بعد الدخول هو المتجر التفاعلي السابق؛ هذا الإصدار لا يحوّل داخل الصورة إلى مجسّم مطابق.
- صور الملابس والمقاسات والأسعار بيانات ديمو؛ لا طلبات أو دفعات فعلية.

## الفحص
`test.py` يقارن لقطات الفتح والإغلاق: كل البكسلات خارج فتحة الأبواب ومنطقة أزرار التحكم تبقى متطابقة، والواجهة المغلقة تطابق الأصل، والإغلاق يعيد الشاشة نفسها. ويختبر الشفافية، منع دوران الواجهة، الدخول للمتجر، عرض قطعة، العودة، واللمس بعرض 390px مع قطع الاتصال بعد التحميل. النتائج وبصمة ملف HTML في verification.json. الاختبار يستخدم متصفحًا برمجيًا وتقليل الحركة؛ لم يُقَس معدل الإطارات على أجهزة فعلية.

## البناء
```
npm install
npm run build
python -m http.server 8925
python test.py
```
`photo-entrance.js` يحتوي حركة البابين، وCSS يسجّلها على الصورة ذات المقاس 1672×941. `build.py` يدمج كل الأصول ويجهز ZIP.
