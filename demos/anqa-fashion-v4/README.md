# ANQA — Atelier 04 · معاينة الواجهة

افتح `ANQA_v4.html` مباشرة. الملف مستقل ويتضمن الأصول والخطوط. ملف ZIP يحتوي HTML في الجذر ومصدر المشروع في ANQA_Source.

## المنجز
- هوية جديدة عاجية وفحمية، تفاصيل برونزية وخطوط وتباعد جديد.
- هيرو بالقطعة مع حركة مرتبطة بالسكرول، وستاند أكثر سماكة وانحناء هادئ.
- تقصير مساحة السكرول الثابتة غير المتحركة.
- تمرير تفاصيل المنتج بعجلة الماوس فوق المشهد، مع إبقاء السحب الأفقي للدوران فقط.
- إدارة موحدة لقفل التمرير، وتحرير السحب عند فقدان التركيز أو مؤشر الماوس.
- عربي وإنجليزي، مقاسات وكميات وحقيبة؛ لا يوجد دفع فعلي.

## حدود هذه المعاينة — لم تُحل بعد
المجسمات هي نفس الأصول التقريبية من v3. التشوه التشريحي وحواف الملابس المقطوعة لم يتم إصلاحهما في هذه النسخة؛ تغيير واجهة العرض لا يحل عيوب المجسم. الإنسان غير مجهز بهيكل عظمي ولا يحرك اليدين. هذه نسخة لمراجعة الواجهة والسكرول والستاند وليست تسليماً نهائياً لمطلب الإنسان الواقعي.

لإكمال العرض المطلوب يلزم إنسان وملابس عالية الجودة بصيغة GLB، بمقياس ثابت وخامات مرخصة وهيكل عظمي وحركات مناسبة. يُفضل تجهيزها أو تصويرها/مسحها ثلاثياً بالأبعاد، مع تطابق الملابس المعروضة. توليد زوايا منفصلة ودمجها لا يضمن ذلك.

## التطوير
`npm ci` ثم `npm run build`.
لفحص المصدر: `python -m http.server 8914` ثم `python test_app.py`.
`python test_360.py` يفحص الملف المستقل دون إنترنت بعد تحميله.
الاختبارات الهندسية للدوران لا تثبت واقعية المجسم.
