# EMBER restaurant menu and table service

Responsive Arabic/English menu, restaurant management and owner/waiter table workspace.

Static frontend: `web/`. Backend: `backend/`. Tests and deployment instructions are included.

Status: Supabase foundation and table service are deployed; public frontend/media publishing and production email setup still need provider configuration. Do not treat the offline demo as a live ordering/payment service. No payment processing is implemented.

See `docs/DEPLOYMENT.md`, `docs/TABLE_SERVICE.md`, and `docs/FREE_TIER_CAPACITY.md` for setup, verification and remaining limits.
