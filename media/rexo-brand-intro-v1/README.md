## Revision workflow

Review `Rexo_Brand_Intro_Silent_v1.mp4`. `Voiceover_AR.txt` is the proposed voice-only script. Scene timings are provisional for silent viewing; replace them with timings from the future supplied narration, retaining narration's natural playback speed.

`render.py` contains the deterministic timeline and compositing code. Run `python render.py --preview` for the contact sheet or `python render.py` for the silent MP4. Requirements: Python, Pillow with libraqm, NumPy, CairoSVG, FFmpeg.
